## 1. 확정된 사실

> 2024학년도 대입부터 학종에서 **자기소개서 전면 폐지**. 2027학년도(2026-11-19 수능 대상) 코호트도 자소서 제출 없음.
> 평가 무게중심: **학생부(내신·세특·창체·활동·독서·행특) + 면접**으로 이동. 학생부의 비중이 오히려 강화됨.

## 4. EPO 권장: **옵션 X**

이유:
1. **cascade 재작업 최소** — 출력 3슬롯 중 1번 슬롯만 교체. WBS·페르소나·CEO §7 매핑은 거의 그대로 유효.
2. **8/1 출시 데드라인 살림** — 8월 = 수시 원서 + 학생부 마지막 정리 시즌. 자소서가 빠져도 학생부 마감 시즌 wedge는 살아있음. 캠페인 카피만 "자소서 마감" → "생기부 마지막 정리·면접 대비"로 리네이밍.
3. **CEO 지침서와 더 깔끔하게 정합** — CEO §7에 자소서 관련 산출물 없음 (자소서/글쓰기는 Writing Coach 영역). 자소서 빼면 두 서비스 분리선이 오히려 선명해짐.
4. **박준호 페르소나의 동기 유지** — "수시 마감 임박"이라는 압박 자체는 자소서 폐지와 무관(학생부 마감·면접 임박은 그대로). 기대 결과물만 교체.

## 5. 옵션 X 채택 시 후속 cascade

| 문서 | 변경 폭 | 주요 변경 |
|---|---|---|
| `definition_v0.1` → **v0.2** | 부분 재작성 | §1 한 줄 정의 교체 / §4-1 자소서 → "생기부 설계 가이드 (학종 평가 기준 기반 문장·활동 정리안)" / §5 비포함 범위 그대로 / §6 Writing Coach 분리선 → 자소서가 Writing Coach 측으로 명확히 분리됨 명시 |
| `wbs_초안_v.3` → **v0.3.1** | 부분 패치 | §1 후보 A 본문 미세 수정(자소서 → 생기부 설계) / §4 M4 명칭 "자소서 시즌 GTM" → "수시 원서·학생부 마감 시즌 GTM" / §7 출시 산출물 학부모 리포트 그대로 / §8 시즌 윈도우 면접 비중 ↑ |
| `personas_v0.1` → **v0.1.1** | 박준호만 손봄 | 박준호 기대 결과물: "자소서 초안 + 면접 답변" → "생기부 마지막 정리·서류 점검 + 면접 답변". 김서연·이미경 변경 없음. |
