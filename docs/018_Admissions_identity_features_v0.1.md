# 입시코치 정체성 기능 — 상태 v0.2 (2026-06-10)

> "생기부 점검기"를 넘어 **학종 입시 코치 정체성**을 갖추기 위한 기능 맵 + 구현 상태.
> 근거: docs/010 정의 v0.4, docs/research(시장), 라이브 pullim.ai/products/exam-coach 참고.

## 학종 여정 커버리지
```
생기부 빌드(고1-2) → 지원 전략(고3 8-9월) → 면접(10-11월) → 결과
```

## Tier 1 — 정체성 정의 (구현됨)
| 기능 | 상태 | 비고 |
|---|---|---|
| 생기부 진단·처방·추적·증명 (폐쇄루프) | ✅ | 엔진+AI+UI, 골든·라이브 검증 |
| **입시 로드맵/캘린더** | ✅ | `engine/roadmap.ts` 결정적 타임라인(코호트별), 결과 상단 오리엔테이션 |
| **면접 준비 팩** | ✅ | `lib/ai/interview.ts` 증거추적 예상질문·답변방향(대본 금지)·꼬리질문 |
| **목표 전공계열 기준 연동** | ✅(계열+대학별) | `engine/criteria.ts` 전공계열 권장방향·평가요소 KB + **대학별 KB 5곳(서울·연세·고려·성균관·한양, verified·sourced)**. intake 목표 대학(최대 3, 칩+직접입력) → `matchUniversity`(정확 일치만, 오매칭 방지) → fit `universityFit` → 결과 카드(검증 출처 표시). 미수록 대학은 정직 폴백(계열 일반 기준 + 모집요강 안내) |

- **수능/정시 성적 분석 · 논술** — 학종 정성 wedge 밖.
