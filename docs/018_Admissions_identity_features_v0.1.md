# 입시코치 정체성 기능 — 상태 v0.1 (2026-06-10)

> "생기부 점검기"를 넘어 **학종 입시 코치 정체성**을 갖추기 위한 기능 맵 + 구현 상태.
> 근거: docs/010 정의 v0.4, docs/research(시장), 라이브 pullim.ai/products/exam-coach 참고.

## 학종 여정 커버리지
```
생기부 빌드(고1-2) → 지원 전략(고3 8-9월) → 면접(10-11월) → 결과
```

## Tier 1 — 정체성 정의 (구현됨)
| 기능 | 상태 | 비고 |
|---|---|---|
| 생기부 진단·처방·추적·증명 (폐쇄루프) | ✅ | 엔진+AI+UI, 골든·라이브 검증 |
| **입시 로드맵/캘린더** | ✅ | `engine/roadmap.ts` 결정적 타임라인(코호트별), 결과 상단 오리엔테이션 |
| **면접 준비 팩** | ✅ | `lib/ai/interview.ts` 증거추적 예상질문·답변방향(대본 금지)·꼬리질문 |
| **목표 전공계열 기준 연동** | ✅(계열) / ⏳(대학별) | `engine/criteria.ts` 전공계열 권장방향·평가요소 KB. **대학별 KB(`UNIVERSITY_CRITERIA`)는 의도적으로 비움(미수록 정직 폴백)** — 정식 데이터(모집요강/대교협/대학 시행계획) 소싱 결정 필요 |

## Tier 2 — 정체성 강화 (구현됨)
| 기능 | 상태 | 비고 |
|---|---|---|
| **전형 적합도(정성 fit)** | ✅ | `lib/fit.ts` 결정적 — 역량별 강함/적정/보완필요, **합격% 금지**, caveat 상시 |
| **전공 적합성·진로 일관성** | ✅ | fit의 consistencyNote |
| **학부모 리포트 강화** | ✅ | ④ 증명에 "지금 입시 단계" + 적합도 요약 추가 |

## ★의도적 비포함 (함정 — 만들지 않음)
- **합격 가능성 예측(점수·%)** — 진학사 데이터 해자 + 가짜점수 금지 원칙 충돌. 정성 fit으로 대체.
- **자소서 첨삭** — 2024 폐지.
- **수능/정시 성적 분석 · 논술** — 학종 정성 wedge 밖.

## 잔여 (product/데이터 결정 필요)
1. **대학별 평가기준 KB 데이터 소싱** — `UNIVERSITY_CRITERIA` 채우기. 출처(모집요강/대교협/대학 시행계획) + EPO 검수. 채우기 전엔 "전공계열 일반 기준 + 미수록 정직 폴백"으로 동작.
2. **재방문 루프 = 카카오 알림톡** (학기별 트윈 넛지) — 채널/영속화 결정(D2~D15).
3. **라이브 2학기 트윈** — intake 2학기 입력(구현됨) + 알림톡 연계.

## 가드레일 (전 기능 공통)
진단(not 설계) · 면접 준비(not 대본) · 처방은 대입-반영(세특/정규창체/행특)만 · 합격% 금지 · 무학습/즉시삭제 · 모든 주장 생기부 근거 인용 · 대학별 데이터 미수록 시 정직 폴백.
