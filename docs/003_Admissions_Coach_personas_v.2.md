## 1. 박준호 페르소나 패치

### 변경 전 (v0.1)

| 항목 | 내용 |
|---|---|
| 상황 | 공학계열 지원. 수시 6장 준비 중인데 **자소서 마감이 2주 남았다**. 학교·학원 모두 바빠 1:1 첨삭을 제때 못 받는다. 면접 일정도 한 달 뒤. |
| 고민 | "**자소서 초안 자체를 못 잡겠다.** 생기부 내용을 어떻게 자소서 문장으로 풀어야 할지 모르겠다." |
| 기대 결과물 | **학종 자소서 초안** (4문항 × 1,500자) + 면접 예상 답변 (질문 10종) |
| 첫 사용 시점 | 고3 8~9월 (수시 자소서 마감 직전, 자소서 시즌 피크) |
| 먼저 누를 기능 | 생기부 업로드 → **자소서 초안 생성** |

### 변경 후 (v0.1.1) — `definition_v0.2.md` 출력 §4-1, §4-2 매핑

| 항목 | 내용 |
|---|---|
| **이름·학년** | 박준호, 고3 2학기 (만 18세) — v0.1 동일 |
| **상황** | 공학계열 지원. 수시 6장 준비 중인데 **원서 마감이 2주 남았고, 학생부 최종 정리와 면접 준비**가 동시에 닥쳤다. 학교·학원 모두 바빠 1:1 코치를 제때 못 받는다. 면접 일정도 한 달 뒤. |
| **고민** | "**내 생기부가 학종 평가 기준에서 어떻게 보일지, 면접에서 뭘 물어볼지 모르겠다.** 마지막에 어떤 활동·문장을 손봐야 할지 판단이 안 선다." |
| **기대 결과물** | **학종 면접 답변** (`definition_v0.2.md` §4-1, 질문 10종) + **생기부 설계 가이드** (§4-2, 학종 평가 기준 5항목 매핑 + 보완 정리안) — 둘 다 24h 안에 1차 초안 |
| **첫 사용 시점** | 고3 8~9월 (수시 원서·학생부 마감 직전 + 면접 준비 시작) |
| **가장 먼저 누를 기능** | 생기부 업로드 → **생기부 설계 가이드 + 면접 답변 동시 생성** |
| **이탈 위험** | 24h SLA를 못 지키면 마감에 못 맞춰 바로 이탈. 결과가 "생기부 복붙 수준"이면 신뢰 상실. (v0.1과 동일) |

## 2. 변경 없음

- **김서연** (고2 1학기, 인문·사회계열, 활동 보완안 중심)
  - 기대 결과물 = 부족 활동 보완안 (`definition_v0.2.md` §4-3) — 자소서 폐지 무관
  - 첫 사용 시점·이탈 위험 등 모든 항목 v0.1 그대로

- **이미경** (고3 학부모, 결제 의사결정자)
  - 기대 결과물 = 학부모 주간 리포트 (§4-3 학부모 리포트)
  - 자녀 진행 상황이 자소서 → 면접·설계 가이드 진행으로 자연 치환됨 (학부모 입장에서 "자녀가 뭘 준비하는지" 본질은 동일)
  - 모든 항목 v0.1 그대로

## 3. 페르소나 간 관계 (v0.1과 동일)

- **박준호 ↔ 이미경 = 같은 가구.** 출시 8/1 직후 매출의 핵심 가구 유형. 자소서 폐지와 무관하게 유지.
- **김서연** = 다음 사이클 파이프라인 (M3 베타).
- 우선순위: M4 자소서 시즌 → **M4 수시 원서·학생부 마감 시즌** 매출 = 박준호 + 이미경 가구 (명칭만 리네이밍, 매출 구조 동일).
