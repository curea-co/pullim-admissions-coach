## ① 한 줄 verdict

**현재 기획(고3 생기부 진단+학종+면접)은 바이브온·생기부ON이 이미 점유한 미투 — 그대로 가면 패배.** 이길 자리는 반대쪽 끝, **고1–2가 "지금 뭘 해서 생기부를 어떻게 채울지"를 연중 처방·실행·증명받는 종단 폐쇄루프(학부모 결제 구독)**다. 리서치 3개 에이전트가 독립적으로 같은 결론에 수렴했다([R] §0). revamp 문서 9종은 이례적으로 잘 정합돼 직접 수정 0건 — **013(해자 #1 루브릭 엔진 스펙)이 야간 재생성으로 작성 완료되어 specs 9/9 완료**, v1.0의 유일한 구조적 약점(013 결손)은 해소됐다. **남은 약점은 013이 지시한 cascade의 *실제 파일 실행* 미완(스키마·프롬프트·골든)**이다.

## ② revamp 핵심 (한눈에)

- **투-스피드:** 코어(전략 본진) = 고1–2 연중 실행 코치·학부모 결제 **월 구독** / 비치헤드 = 고3 수시·면접 시즌을 **시간한정 획득 캠페인**으로 → 구독 전환 깔때기. 8/1은 "정체성"이 아니라 "획득 이벤트".
- **엣지 = 폐쇄루프:** read-only 1회성(경쟁사 전부 BM·데이터 위치상 못 바꿈) → **진단→처방→실행→증명** 종단 루프. 면접은 간판이 아니라 루프의 한 노드로 강등(가장 늦고·짧고·싼 1회성 창, [R] §4-2 #4).
- **3대 해자:** #1 코호트-인식 "평가기준→합법 액션" 루브릭 엔진(유지보수형 IP, 골든회귀로 보호) · #2 종단 생기부 디지털 트윈(증거인용·**무학습/즉시삭제** = 바이브온 신뢰논란 정면 차별) · #3 풀림 OS 상류 활동데이터(day-1엔 없음, 시간 갈수록 복리).
- **8/1 출시안(a):** #1+#2 독립형 출시(#3는 코어에서 복리 축적).

## ④ 무엇을 바꿨나 (v0.3 → v0.4 핵심 5)

1. **정체성:** read-only 진단기 → **종단 생기부 실행 루프**.
2. **타깃:** 고3 시즌 단일 → **고1–2 연중(코어) + 고3(비치헤드) 투-스피드**.
3. **면접:** 간판 산출물 #1 → **루프의 시즌 노드로 강등**.
4. **가드레일 명문화:** 처방은 **대입-반영 항목만**(✅세특·정규 창체·행특 / ❌수상·자율동아리·외부봉사·독서·자격증 / ⛔소논문·교외수상·기관명) — v0.3은 "학생 본인이 앞으로"만 있고 항목이 비어 있었다.
5. **코호트 분기(P0):** 2027 구체제 / 2028·2029 신체제(5등급제→정성평가 의존↑), 입학연도로 결정 — 분기 없으면 구조적으로 틀린 조언.
