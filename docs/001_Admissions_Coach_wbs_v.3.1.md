## 3. 핵심 영향

1. **출시 데드라인 유지.** 8/1은 "자소서 시즌"이 아니라 "수시 원서·학생부 마감 시즌"으로 재해석되며, wedge는 그대로 살아있음.
2. **M1 산출물 1건 추가.** "학종 평가 기준 5항목 매핑표"가 신규 (생기부 설계 가이드의 근거). M1 본인 시간 32h 안에 흡수 가능 — 자소서 문체 가이드 작성 시간으로 대체.
3. **Domain Content 작업량 ≈ 동일.** 자소서 문체 가이드 → 평가 기준 매핑 + 면접 답변 톤. 작업 성격만 바뀜.
4. **시즌 GTM 자연 정렬.** 8월 수시 원서·학생부 마감 → 10~11월 면접 → 11/19 수능 → 정시 면접/논술. 자소서 시즌이라는 가짜 윈도우가 빠지고 진짜 시즌이 더 또렷해짐.

## 6. v0.3.3 패치 — CEO 평가 피드백 인테이크 (2026-06-01)

| **경쟁사 분석 v1** | 학종 면접·생기부 진단 + 초등 교육 시장 다각도 분석. 컬럼: 서비스명·타겟·핵심 기능·**수익성(가격·BM)**·**유저 수(MAU/DAU)**·**기술 구현 용이성**·차별 포인트·우리 wedge 영향. 1차 5~10개 앱 | M1 1주차 (6/5 금) |

근거: CEO 평가 = 기능 80%/정책 30%. 정책 30% gap을 5건으로 분류 → M1~M2 안에 닫지 못하면 8/1 출시 위험 (§9 ⚠️ 트리아지 미성년자 동의 P0 blocker와 동일 라인).

### 6.2 운영 룰 1건 추가 (§5 본인 시간 캡 영향 없음)

- **AI 활용 폭 확장 룰** — admissions M1 이후 모든 산출물은 (a) 단순 기능 구현이 아닌 아키텍처·UX·차별화 설계에 AI 적극 활용, (b) 산출물 상단에 "AI 위임 부분 / EPO 직접 부분" 1줄 표기. 본 룰은 `feedback_ai_usage_expansion` 메모리와 연동.

### 6.3 영향

- M1 본인 시간 32h 캡 — "능동 제안" 1건/주(~2h) + 경쟁사 분석 1차(~6h) + 정책 점검표(~4h) = +12h. 자소서 폐지로 확보된 슬랙(자소서 문체 가이드 제거분)으로 흡수 가능. 초과 시 골드 데이터 5건 형태 검수만 PM 시간으로 이관.
- 8/1 출시 데드라인 무변경. 다만 정책 점검표 5건 모두 "닫힘" 조건 미충족 시 출시 차단 — §9 트리아지 미성년 동의 P0 blocker 와 묶어서 운영.
