## 1. 한 줄 정의 (확정)

> **생기부를 넣으면 학종 면접 답변·생기부 설계 가이드·부족 활동 보완안을 한 번에 받는, 고1~고3을 위한 AI 진학 코치.**

---

## 2. 독자 정의

| 순위 | 독자 | 사용 시점 | 가치 제안 |
|---|---|---|---|
| 1차 | **고1~고3 학생** | 수시 원서·학생부 마감 시즌(7~9월), 면접 시즌(10~11월) | 생기부 기반 면접 답변·설계 가이드를 24h 안에 받음 |
| 2차 | **학부모** | 자녀 진학 의사결정·결제·진행 모니터링 | 자녀 진행을 주 1회 리포트로 받음 |

결제 의사결정자는 학부모, 매일 쓰는 사용자는 학생. v0.1과 동일.

---

## 3. 핵심 입력 (학생이 넣는 것)

1. 생기부 PDF 또는 텍스트 붙여넣기 (마스킹된 형태)
2. 지원 학부 4계열 중 택 1 (인문 / 공학 / 의학·자연 / 예체능)
3. 목표 대학 3순위 (선택)
4. **현재 학년·학기 + 학교 유형** (일반고 / 특목고 / 자사고) ※ v0.1 대비 신규 — 생기부 설계 가이드의 평가 기준이 학교 유형별로 미세하게 달라짐
5. 본인이 부족하다고 생각하는 영역 (자유 텍스트, 선택)

세부 schema는 `student_profile_schema_v0.1.json` (대기 중)에서 닫는다.

---

## 4. 핵심 출력 (AI가 주는 3종)

| # | 산출물 | 형식 | 운영 SLA |
|---:|---|---|---|
| 1 | **학종 면접 답변** | 학종 면접 예상 질문 10종 × 답변 초안 | 24h 안에 1차 초안 |
| 2 | **생기부 설계 가이드** ※v0.2 신규 | 학종 평가 기준 5항목(학업역량·진로역량·공동체역량·인성·기타) 매핑 + 부족한 항목 보완 문장·활동 정리안 | 24h 안에 1차 가이드 + 본인 검수 코멘트 |
| 3 | **부족 활동 보완안** | 생기부 키워드 추출 + 학부 적합도 차이 + 보완 활동 제안 3건 | 즉시 (요약 화면) + 학부모 리포트 (주 1회) |

v0.1의 §4-1 "학종 자소서 초안"은 제도 폐지로 삭제. 출력 슬롯 3개 구조는 유지.

## 6. Writing Coach와의 분리선

자소서 폐지로 분리선이 v0.1보다 더 선명해짐:

| 구분 | Pullim Writing Coach | Pullim Admissions Coach |
|---|---|---|
| 입력 | 임의의 글 (수행평가·내신 글쓰기) | 생기부 (구조화된 학생 이력) |
| 1차 독자 | 중·고 학생 | 고1~고3 학생 |
| 출력 | 5영역 채점 + 첨삭 피드백 | 면접 답변 + 생기부 설계 + 활동 보완안 |
| 시즌성 | 통년 (수행평가) | 학종 시즌 (8~11월) |

분리선 명문화: **임의의 글을 평가·첨삭하는 도구 = Writing Coach. 생기부를 분석해 학종 평가에 맞게 설계·면접 답변을 만드는 도구 = Admissions Coach.**
