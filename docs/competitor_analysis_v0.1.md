## 1. 목적 & 범위

- **목적**: pullim-admissions-coach (학종 면접 준비 + 생기부 진단) 의 wedge가 실제 시장에서 통하는지 검증, 차별화 기능·정책 5건 도출

- **범위 2 (Secondary 참조)**: 초등 교육 시장 (cross-domain learning — 수익성 BM·유저 획득·기술 구현 측면 패턴 학습)
- **금기**: 단순 필터링·이름 나열. CEO 평가 명시 — "수익성, 유저 수, 기술적 구현 용이성 등을 다각도로 분석"
