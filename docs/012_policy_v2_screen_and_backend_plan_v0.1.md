## 1. 목적

정책서 v2.0 조항을 현행 구현과 대조해 갭을 없애는 FE 화면 개선 + BE 구현을 정의한다.
정책 §2-3·§6이 **"출시 차단 조건"**으로 명시한 미성년 보호(가림·동의·**동의 후 저장**·저장보호·보관/삭제)를 P0로 둔다.

## 2. 확정된 접근 모델 (§7, 게이트키퍼 합의)

| 사용자 | 접근 범위 |
|---|---|
| **게스트**(비로그인) | 전 화면 진입 불가 → OS 로그인(`os.pullim.ai/login?next=`) (§7-1) |
| **무료 회원**(로그인·이용권 없음) | 홈(소개)·설정 + 홈의 **"결과 예시 먼저 보기"** → 예시(데모) 화면 (§7-2) |
| **유료 회원**(admissions 이용권 보유) | 진단 여정 전체: 제출 · 동의 · 진행 · **결과** (§7-3) |

- `/result`(진단 결과)는 **유료 게이트**. 무료 데모는 홈 진입점 **"결과 예시 먼저 보기"**의
  **별도 예시 화면**으로 분리(박준호 목업 재사용) → §7-3과 무료 체험 양립.
- 이용권 판정은 통합 계정 위임(`GET /me/entitlements`·`flags.admissions`) (§7-5). 결제(학부모·토스)는 OS, 앱은 결제 후 재확인(§7-4).

## 6. 후속/외부 의존 (§8 검토중)

- 보호자 동의 채널(카카오 알림톡) 실 발송 — B7·동의 확인 연계.
