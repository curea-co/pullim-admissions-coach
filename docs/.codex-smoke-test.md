## 예상 fail mode

| 증상 | 원인 | 처리 |
|---|---|---|
| Job 자체 미트리거 | GitHub App 미설치 | 봇 개발자에게 App install 요청 |
| Job 실행되나 secret 접근 실패 | org secret 의 "Selected repositories" 에 admissions 미포함 | 봇 개발자에게 org secret 권한 요청 |
| Job 실행되나 runner 미할당 | runner group `curea-runner-groups-2` 에 admissions 미포함 | 봇 개발자에게 runner group 권한 요청 |
| Job 완료되나 review 미게시 | App token 권한 부족 (pull-requests:write 누락) | App 권한 확인 |
