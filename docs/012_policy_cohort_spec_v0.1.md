| 코호트 | 수능 조언 규칙 | CONFIRMED/UNCERTAIN |

### 2.4 전공 권장과목 조언 분기 (신체제 핵심, 고교학점제 연계)

신체제는 고교학점제 진로선택과 대학별 권장과목이 **과목선택의 핵심 변수**로 부상. 코치는 목표 전공계열별 권장과목을 처방의 입력으로 사용한다.

| 전공계열 | 권장과목(예시) | CONFIRMED/UNCERTAIN |
|---|---|---|
| 이공(자연) 공통 | 수학: 대수·미적분Ⅰ·확률과통계(경희대 핵심), 기하·미적분Ⅱ(서울대 권장) / **과학 3과목 이상 이수 권장** | CONFIRMED(§10) — **단 대학·학과별 상이** UNCERTAIN |
| 의예 | 생명과학 우선 이수 권장 | CONFIRMED(§10) |
| 약학 | 화학 또는 생명과학 우선 이수 권장 | CONFIRMED(§10) |
| 인문/사회 | 사회·제2외국어·심화 국어/영어 등(대학별 권장 편차 큼) | UNCERTAIN(대학별 상이) |
| 의치한·예체능·기타 | 계열별 권장과목 대학별 시행계획 직접 확인 필요 | UNCERTAIN |

**설계 제약(필수):** 권장과목 데이터는 **대학·학과마다 제각각**이며(서울대 기하·미적Ⅱ 핵심 vs 고려대 수학과목 미지정 등, §10), 대교협이 권역별 권장과목을 공개·갱신 중이다. 따라서 해자 #1 엔진은 권장과목을 **하드코딩하지 말고 "대학별 시행계획 출처를 인용하는 데이터 레이어"로 유지**하라. 코치 출력에는 항상 **"지망 대학 시행계획 직접 확인"** 안내를 붙인다(허위·구식 정보 책임 리스크 차단, [R] §4.4 정확도/책임 KILLER).

## 4. 학종 비중·권역 분기 규칙

코칭은 "목표대학 권역"으로 분기 필수. 권역에 따라 수시:정시 비중과 전략 무게가 다르다([R] §3.2).

### 4.1 권역별 수시·정시 비중 (2027학년도 기준)

| 권역 | 수시 : 정시 | 전략 무게 | 근거 |
|---|---|---|---|
| 전국 평균 | 80.3 : 19.7 (수시 첫 80% 돌파) | 학종·교과 중심 | [R] §3.2 / §10 CONFIRMED |
| 수도권 | 65.8 : 34.2 | 정시 비중 상대적 높음 → 수능 병행 | [R] §3.2 / §10 CONFIRMED |
| **서울 상위권(16개대)** | **정시 40%+ 유지**(서울 15개대 57.5:42.5) | 정시 비중 최고 → **수능+학생부 정성 병행** | §10 CONFIRMED |
| 비수도권 | 89.5 : 10.5 | 수시(학종·교과) 집중 | [R] §3.2 CONFIRMED |

서울 16개대(정시 40%+ 대상): 건국대·경희대·고려대·광운대·동국대·서강대·서울대·서울시립대·서울여대·성균관대·숙명여대·숭실대·연세대·중앙대·한국외대·한양대 (CONFIRMED §10).

### 4.2 권역 분기 코칭 규칙

| 목표 권역 | 코치 분기 규칙 |
|---|---|
| 서울 상위권 | "정시 40% 룰 잔존 → 수능 사수 + 세특(정성) 병행". 신체제 코호트는 정시 정성평가 도입(§4.3) 강조 |
| 수도권 일반 | 수시 우세하나 정시 1/3 → 학종 주력 + 수능 안전판 |
| 비수도권 | 수시 9할 → **학종·교과 집중**, 정시 비중 낮음 안내. 세특·교과 성취가 사실상 결정 |

### 4.3 신체제 정시 정성평가 — 구조적 tailwind (코칭 메시지 근거)

신체제(2028·2029)에서 **정시에도 학생부 정성평가가 도입·확산** 중. 2025년 발표된 대학별 시행계획이 이를 구체화:
- **건국대:** 정시 수능위주전형에 정성평가 도입 — 수능 80% + 학생부 정성평가 20%(과목 이수 이력·세특 중심, 진로적성 과목선택 적절성·이수 깊이·성취수준·학습 충실도 평가). CONFIRMED(§10)
- **서울대:** 정시에 교과역량평가 40% 반영. CONFIRMED(§10)
- 함의: 신체제 코호트는 **"정시 지망이어도 세특이 점수가 된다"** → 세특(§3 ✅ 최우선) 연중 관리가 전 지망자에게 유효. = 코어(고1–2 연중 구독)의 구조적 정당성 강화([v0.4] §7 tailwind와 정합).
